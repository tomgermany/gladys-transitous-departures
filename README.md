# Gladys external integration — Transitous

Hier finden sie eine externe Integration für Gladys Assistant. 
Sie zeigt die nähesten und nächsten Abfahrtsmöglichkeiten in einem frei wählbaren Umkreis um ihre Geolocation an.

Diese Entwicklung benötigt eine Installation von Gladys Assistant als Grundlage.

Anwenderinformationen: ![Englisch](docs/en.md) and ![Französich](docs/fr.md)

![Ergebnis der Integration](test/cover.png)

Ein Beispiel mit Lissabon:

![Ergebnis der Integration](test/lissabon.png)

Sie erhalten u.a. die nächsten Abfahrten von  Fähren im Linienverkehr, Seilbahnen im Linienverkehr, Busse, Überlandbusse, Straßenbahnen, Schnellzüge und weitere in einem von ihnen festlegbaren Suchkreis um eine Geolocation.

Übrigens, zur Zeit vier Sprachen Spanisch, Englisch, Deutsch und Französisch, Kalaallisut und Koreanisch.

Hinweis:

Data provided by [Transitous](https://transitous.org/). Please see the [Transitous data sources and attribution information](https://transitous.org/sources/).
